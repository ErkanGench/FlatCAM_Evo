Keyboard Distance Input Feature Description
Principle
The "Keyboard Distance Input Feature" is a geometric drawing principle that enables users to precisely control the placement and size of geometric elements by combining mouse positioning with keyboard distance input. The core concept allows users to:
1. Set Direction: Position the mouse cursor in a specific direction from a reference point
2. Input Distance: Type numeric values using the keyboard (0-9, decimals, mathematical operators) to specify a precise distance or dimension
3. Execute Placement: Press Enter to create the geometric element at the calculated position based on the mouse direction and keyboard-entered distance
This principle provides an alternative to purely visual/interactive geometry creation, offering precision through numeric input while maintaining intuitive direction control through mouse positioning.
Implementation Details
The feature is implemented consistently across both editors using a standard pattern:
1. Keyboard Event Capture (on_key method)
# Capture numeric input keys (0-9, +, -, *, /, ., ,)
if key in [str(i) for i in range(10)] + ['.', ',', '+', '-', '/', '*'] or \
        key in [QtCore.Qt.Key.Key_0, ..., QtCore.Qt.Key.Key_9, ...]:
    # Process key input for distance value
    try:
        # Handle VisPy keys
        if self.tool.length == 0 or self.new_segment is True:
            self.tool.length = str(key.name)
            self.new_segment = False
        else:
            self.tool.length = str(self.tool.length) + str(key.name)
    except AttributeError:
        # Handle Qt keys  
        if self.tool.length == 0 or self.new_segment is True:
            self.tool.length = chr(key)
            self.new_segment = False
        else:
            self.tool.length = str(self.tool.length) + chr(key)
2. Enter Key Processing
if key == 'Enter' or key == QtCore.Qt.Key.Key_Return or key == QtCore.Qt.Key.Key_Enter:

        target_length = self.tool.length
        if target_length is None:

3. Standard Integration Points
- Jump-to Coordination: The 'J' key triggers coordinate jumping functionality
- Cursor Data Display: The 'C' key toggles cursor coordinate display
- Backspace Support: Removes the last entered point
- Visual Feedback: Messages displayed to inform user of projected distances
4. Tool-Specific Variations
- Path/Polygon tools: Store multiple points, create segments
- Circle/Rectangle tools: Calculate dimensions based on direction and input
- Track/Pad tools: Project elements in direction based on mouse angle
5. Technical Architecture
- Parent Class: All tools inherit from DrawTool base class which defines the basic on_key interface
- Tool State: Tools maintain their own state (length, radius, width values) in associated plugin UI objects
- Coordinate System: Uses application coordinate system with mouse position tracking
- Distance Calculation: Uses trigonometric calculations to maintain direction while applying numeric distance
The feature represents a hybrid interaction model that combines the precision of numeric input with the intuitiveness of mouse-based direction control, allowing users to create precise geometric elements efficiently.
